# Ассистент внедренца

AI-помощник руководителя проектов внедрения. Разбирает заметки со встреч,
превращает их в задачи и записывает в рабочий реестр и календарь.

## Какую задачу решает

Внедренец ведёт несколько проектов одновременно. После каждой встречи
остаются заметки, из которых нужно вытащить договорённости, завести задачи,
поставить дедлайны — и не потерять то, что обещал заказчик. На практике это
делается вручную или не делается вовсе, а перед следующей встречей человек
судорожно вспоминает, о чём договаривались в прошлый раз.

Ассистент закрывает оба конца этого цикла:

- **после встречи** — разбирает заметки, выделяет задачи с ответственными и
  сроками, показывает на подтверждение и записывает в реестр и календарь;
- **перед встречей** — поднимает историю проекта: о чём договорились, что с
  тех пор не сделано, что просрочено, какие вопросы висят на заказчике.

Реестр наполняется первым сценарием и используется вторым — система
накапливает контекст по мере работы.

## Как это работает

```
веб-чат  →  агент (LLM + function calling)  →  Google Sheets / Calendar
                        ↓
                 журнал действий
```

Агент получает сообщение, сам решает, какие инструменты вызвать, и выполняет
их последовательно, пока не соберёт ответ. Всё, что он делает с внешними
системами, отображается в журнале справа: имя инструмента, аргументы,
результат. Чтения и записи различаются визуально.

### Инструменты

| Инструмент | Действие |
|---|---|
| `get_project_context` | карточка проекта, последние встречи, открытые задачи |
| `list_overdue_tasks` | просроченное, ближайшее, отдельно — задачи без срока |
| `add_tasks` | **запись** новых задач в реестр |
| `update_task` | **изменение** срока или статуса существующей задачи |
| `create_deadline` | **создание** события в Google Calendar |

### Что заложено сверх минимума

- **Подтверждение перед записью.** Ассистент показывает, что собирается
  записать, и ждёт согласия. Автоматическая запись без спроса в рабочем
  инструменте недопустима.
- **Защита от дублей на уровне кода.** Перед записью задача сверяется с
  открытыми задачами проекта по доле общих слов. Дубль не создаётся, а
  возвращается человеку с номером уже существующей задачи. Правило есть и в
  промпте, но промпт может подвести на слабой модели — код не может.
- **Валидация дат.** Некорректный формат срока отклоняется с объяснением,
  модель исправляется на следующем шаге. В таблицу мусор не попадает.
- **Готовые ориентиры дат в промпте.** «До конца недели» и «в понедельник»
  считаются заранее и передаются модели готовыми — сами модели считают
  относительные сроки плохо.
- **Задачи без срока не считаются просроченными** — выделены в отдельную
  категорию.
- **Поиск проекта с учётом склонений** — «ТехноСнабом», «с Ромашкой»,
  «Ромашке» находят один и тот же проект.
- **Провайдер модели — параметр конфигурации.** Gemini и GigaChat
  совместимы по формату, переключение делается двумя строками в `.env`
  без изменения кода.

## Стек

Python, FastAPI, OpenAI SDK (совместимый режим), Google Sheets API,
Google Calendar API. Модель — Gemini 3.x Flash, интерфейс — одностраничный
веб-чат без фреймворков.

Реестр живёт в Google Таблице. Для прототипа это осознанный выбор: данные
видны и правятся руками, а структура повторяет то, как внедренцы реально
ведут проекты. В продуктиве на это место встаёт Битрикс24 или 1С — меняется
только модуль `sheets.py`.

Интерфейсов три: веб-чат, Telegram-бот и консоль. Ядро агента
(`agent.py`) не знает, откуда пришло сообщение, — интерфейс подключается
сбоку. Веб-версия показывает журнал вызовов инструментов рядом с диалогом,
Telegram удобнее для реального сценария: надиктовать заметки сразу после
встречи, не открывая ноутбук.

## Запуск

Нужен Python 3.9+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните. Понадобятся:

1. **Ключ модели** — Google AI Studio, бесплатный тариф.
2. **Сервисный аккаунт Google** — в Google Cloud Console включите Sheets API
   и Calendar API, создайте сервисный аккаунт, скачайте JSON-ключ в
   `credentials.json`.
3. **Таблица** — импортируйте `potok_demo_data.xlsx` в Google Таблицы и
   выдайте сервисному аккаунту права редактора. ID — из адресной строки.
4. **Календарь** — создайте отдельный календарь, выдайте сервисному аккаунту
   право изменения событий. ID — в настройках календаря.

Проверка доступов перед запуском:

```bash
python check_setup.py
```

Запуск:

```bash
uvicorn web:app --reload      # веб-интерфейс на http://127.0.0.1:8000
python bot.py                 # Telegram-бот
python cli.py                 # консольный режим для отладки
```

Три интерфейса работают с одним и тем же агентом: `agent.py` не знает,
откуда пришло сообщение. Для Telegram нужны `TELEGRAM_TOKEN` и
`ALLOWED_USER_ID` в `.env`.

## Демонстрационные данные

`potok_demo_data.xlsx` — три листа: проекты, встречи, задачи. Три вымышленных
проекта внедрения с историей за три месяца. Часть задач намеренно просрочена,
у части ответственный на стороне заказчика.

## Что попробовать

- `Подготовь меня к встрече с ТехноСнабом` — бриф с историей и открытыми
  вопросами
- `Что горит на этой неделе?` — сводка по всем проектам
- Вставить заметки со встречи → подтвердить → задачи в реестре, событие в
  календаре

## Ограничения прототипа

- История диалога хранится в памяти процесса, рассчитана на одного
  пользователя; перезапуск сервера очищает переписку
- Бесплатный тариф Gemini ограничен несколькими запросами в минуту — при
  упоре в лимит агент ждёт и повторяет автоматически
- Поиск по проектам работает перебором: при сотнях проектов понадобится
  индекс или векторный поиск
- Нет аутентификации — интерфейс рассчитан на локальный запуск

## Что добавил бы дальше

1. **Битрикс24 вместо таблицы** как источник задач и сделок — основной
   сценарий для реального заказчика.
2. **Голосовой вход** — надиктовать заметки сразу после встречи с телефона
   вместо того, чтобы печатать.
3. **Проактивный дайджест** — утренняя сводка по зависшим задачам без
   запроса, отдельным сообщением.
4. **Векторный поиск по документам проекта** — когда материалов станет
   больше, чем помещается в контекст. Сейчас это было бы преждевременным
   усложнением.
